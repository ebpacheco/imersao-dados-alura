**Imersão Dados - Alura**<br>

Projeto desenvolvido durante a Imersão de Dados da Alura, focado em análise exploratória de dados (EDA) utilizando Python e bibliotecas populares de Data Science.<br>
O objetivo foi explorar um dataset real, aplicar técnicas de análise de dados e gerar insights a partir de visualizações e estatísticas. A imersão apresenta conceitos de análise de dados, machine learning e storytelling com dados ao longo de aulas práticas.<br>

**Tecnologias Utilizadas**<br>
Python<br>
Jupyter Notebook<br>
Pandas<br>
NumPy<br>
Matplotlib<br>
Seaborn<br>

**O que foi desenvolvido**<br>
Durante o projeto foram aplicadas etapas fundamentais do fluxo de análise de dados:<br>
Importação e exploração do dataset<br>
Limpeza e tratamento de dados<br>
Análise exploratória (EDA)<br>
Visualização de dados<br>
Análise estatística<br>
Geração de insights a partir dos dados<br>

**Conceitos Aplicados**<br>
Data Exploration<br>
Data Cleaning<br>
Data Visualization<br>
Estatística aplicada<br>
Storytelling com dados<br>
Introdução a Machine Learning<br>
